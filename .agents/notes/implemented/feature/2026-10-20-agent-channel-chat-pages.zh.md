# Agent Note: 助手频道聊天页面

Status: implemented

[English](2026-10-20-agent-channel-chat-pages.md) | 中文

## Problem

模态频道记录会妨碍用户在助手收件箱与协作消息之间正常导航。频道行也需要与助手行相同的宽度、选中反馈和清空菜单。

## Decision

布局拥有根作用域的 `conversation.page` 列表插槽，并通过 `layout.openPage` 按注册标识选择页面。空页面恢复当前会话。收件箱负责频道选择和记录，注册只读频道页面，并在打开频道行时选中该页面。选择助手会恢复其会话，不会创建频道会话或中断正在进行的工作。

频道行使用收件箱行结构及其下拉确认流程。清空仍是按用户隔离的 API 操作。只有确认框使用模态窗口；频道内容位于中央聊天区。

## Alternatives considered

**模态记录。** 频道记录是主要阅读目标，必须让侧栏导航保持可用，因此不采用此方案。

**模拟助手会话。** 协作消息拥有独立记录和归属。将其模拟为助手会话会引入不属于它的输入通道和模型生命周期，因此不采用此方案。

## Consequences

布局除了会话选择外，还保存临时的中央页面选择。重新加载会重置频道选择，助手记录和草稿仍由原有会话控制器管理。打开中央页面会关闭详情栏。组件检查覆盖中央页面导航和下拉确认；e-server 的 Chromium 测试验证实际页面位置、行宽相等、无输入控件、清空操作，以及返回助手输入界面。
