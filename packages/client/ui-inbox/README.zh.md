# @deepseek-ai/dsh-client-ui-inbox

[English](README.md) | 中文

这个家庭部署插件为登录用户可使用的每个助手提供一个固定的侧栏收件箱行。通过身份验证的 e-server API 提供名单、名称、会话标识和频道列表；浏览器不内置家庭助手名单。

## 导航与频道

助手行通过 `/v1/browser/inbox/open` 解析其固定会话。控制器先刷新运行时会话列表，再选择返回的标识，以便输入区绑定已存在的会话。打开行不会任意创建客户端会话。工作目录由 e-server 按助手配置。

助手频道通过布局的 `conversation.page` 插槽占据中央聊天区。频道行与收件箱行具有相同的完整宽度和选中反馈。两种行都通过下拉菜单和确认框提供清空操作。频道页面只显示记录和刷新按钮，没有输入、编辑控件或模型生命周期。没有消息的频道显示未选中欢迎页所用的家庭标记，而不是一句提示文字；正在读取或读取失败的频道仍显示自己的加载或错误提示行，不会显示该标记。选择助手行会恢复其会话，不会中断正在进行的工作。

后端按登录用户隔离频道记录、可用组合和清空操作。清空频道会删除共享记录和未发送的通知；已接收的消息仍保留在接收助手的会话中。

## 在线状态与未读轮次

名单包含已禁用的助手；其行显示离线和已禁用，不能启动会话。绿色代表在线，红色代表离线，白色代表正在工作，蓝色代表有未读的已完成回复，琥珀色代表终止轮次的致命错误。频道只有在双方都可用时显示绿点。模型重试和可恢复的工具错误不会产生琥珀色状态。

助手自己的轮次正在运行，或其下任意深度的会话仍在运行时，该行显示正在工作，并使用该助手自己的动词：Delta 和 Darwin 显示 `正在工作...`，Diana 显示 `聊天中...`，Dexter 显示 `思考中...`，当前版本不认识的助手显示 `正在工作...`。只要有一个正在运行的子助手，数量就直接写在后面，如 `正在工作... (2)`，圆点的无障碍标签使用同一个字符串。在这个外观中子助手不可见，因此父行是显示它们工作的位置。数量跟随客户端会话存储，子助手开始或结束会在无需刷新收件箱的情况下更新该行；没有正在运行的子助手时不显示数量，而不是显示 `(0)`。当行数据还报告了等待工作名额的委派（`queuedWorkers`，属于服务器知识，浏览器无法推导）时，同一个字符串改为显示一对数字：`Working... (3/4)` 表示三个正在工作，还有一个仍在排队。该分母是当前这份数据中的“正在工作 + 排队”，因此会随着队列排空而变小——排队的助手开始工作后，该行回到单个数字（`Working... (4)`），而不是保留 `(4/4)`。分子会立即随会话帧更新，排队数字则在下一次常规收件箱读取时更新，因此刚启动的瞬间可能有一个刷新周期的滞后。没有正在工作的助手时，无论有多少在排队，该行都只显示 `Working...`，因此永远不会出现 `(0)` 或单独的 `/`；数据中没有该字段时，行为与以前完全相同。

完成轮次与致命错误标记来自可信主机事件，按用户与助手的固定会话持久保存。当相应会话被选中、可见且空闲时，浏览器只确认它实际显示的完成序号。即使确认操作与后续完成事件竞争，新的回复仍保持未读。阅读频道或子助手不会将父助手收件箱标为已读。

竖屏只改变形状，不改变内容。浏览区域从侧边栏外壳收到 `portrait`：此时轨道只画头像——每个助手行一个字形、每个频道行一个字形，各自保留本行的可访问名称（`打开与 X 的对话`，或频道自己的名称）以及 `aria-current` 选中状态；点击字体会在当前视图打开该对话，而不是把收件箱铺到聊天上。每次选中（助手行、轨道字形、频道行）都会先调用 `collapseOnSelection`，因此选中的对话一次点击就恢复整屏；该回调只在竖屏生效，列已收起时为空操作，所以手动展开绝不会被渲染撤销。状态文案（`正在工作... (3/4)` 等）、时间戳、分区标题、菜单、刷新控件和设置标签在轨道模式下根本不渲染，而不只是隐藏。

## 扩展点

插件占据 `sidebar.workspaces`，并注册 `agent-channel` 中央页面。插槽注入发布控制器快照和回调；组件只渲染这些属性。这个部署不组合会话列表、工作目录浏览器和新建会话插件。

## Model Experience

无；收件箱导航和频道渲染不注册模型上下文，助手通知的投递由 e-server 主机插件负责。

#### KV Cache effect

无；这个浏览器插件既不组装提供商请求，也不写入会话事件。

## Known Limitations and Deferred Work

- 浏览器同源位置必须提供家庭 e-server 收件箱和频道 API。
- 频道选择是临时状态，重新加载会重置选择；后端保留记录。
- 频道记录显示最近 200 条消息，并在选中时刷新。
