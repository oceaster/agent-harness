# @deepseek-ai/dsh-client-ui-settings-learn

[English](README.md) | 中文

这个家庭部署插件负责设置弹窗的 **了解更多** 标签页。它按登录用户可使用的每个助手逐条说明：这个助手是做什么的、它如何工作、它不会做什么，以及怎样与它配合——是一份紧凑的参考速查表，而不是宣传页面。

这些文字不属于插件。e-server 从 `context/agent-guides.json` 出发，经由 `GET /v1/browser/learn` 提供，走的是与本页面相同的源根路径（不是页面自己的 `/_dsh/` 前缀）。档案 cookie 就是全部的身份验证，因此插件不发送身份，也不内置任何助手标识、助手名称、小节标识或说明正文：服务器发来什么，标签页就按服务器的顺序渲染什么。修改说明因此是 e-server 的内容变更，无需重新构建浏览器包。

## 接口

```json
{
  "person": { "id": "owen", "name": "Owen" },
  "agents": [
    {
      "agent": "delta",
      "name": "Delta",
      "enabled": true,
      "summary": "…",
      "sections": [{ "id": "what-it-is-for", "title": "…", "body": "…\n\n…" }]
    }
  ]
}
```

`sections[].body` 是纯文本，段落之间用一个空行分隔，不含 markdown、不含 HTML，每一段单独渲染为一个 `<p>`。小节列表是开放的：各助手的最后一个小节并不相同（Delta 的等待/工作者小节、Darwin 的交接小节、Diana 的记忆小节），标签页按到达的内容渲染，而不是按它认识的一堆固定小节。

形状被破坏的响应体（某个助手或某个小节缺少必填字段）会被拒绝为无法解析的应答，并显示为失败状态。而在服务器上增删整个小节不算破坏：标签页会跟着变。

## 状态

四种状态，各自独立成屏：

| 状态 | 触发条件 | 屏幕 |
| --- | --- | --- |
| 加载中 | 读取尚未返回 | 一行加载提示 |
| 就绪 | 200 且带助手 | 速查表 |
| 就绪但为空 | 200 且 `"agents": []` | 「这个档案没有可用的说明」 |
| 失败 | 其它任何非 2xx，或无法解析的响应体 | 服务器自己的句子加一个重试按钮 |
| 被拒绝 | 403 | 拒绝说明，没有重试 |

空名单和拒绝是两件不同的事，绝不会互相渲染：`agents: []` 是对一个真实登录用户的策略答复（「这个档案不能开启任何助手」），而 403 是部署拒绝了这个档案——在本部署中它甚至发生在 learn 路由执行之前（Guest 返回 `{"detail": "DSH is unavailable to Guest"}`）。

失败时会读 `body.detail`，FastAPI 的包装形式有两种：`HTTPException(500, "…")` 给出字符串，`HTTPException(502, {error, code, message})` 给出对象。这句话正是屏幕上最有用的信息——e-server 会点名缺少说明的助手，或说明 harness 正在重启——所以它被原样显示；字典里按代码准备的文案只在响应体没有可读句子时才使用。重试会真正重新请求，若再次失败就再次显示失败内容，从不宣称成功。

## 布局

小节铺满设置面板的内容列，并随它一起滚动。每个助手是一个紧凑的区块：名称、摘要，然后每个小节一行带标签的段落；助手之间用一条分隔线而不是各占一张卡片。小节行在较宽的内容宽度下把标题放在窄的左栏、正文放在右侧，视口低于 760px 时改为单列堆叠，因为那时面板已经太窄。所有文字位都会对长单词换行，两列宽度都可收缩到零，因此在任何宽度下面板都不会出现横向滚动条。

## 扩展点

插件注册一个 `settings.section` 条目（`id: learn`，`order: 5`，位于 General 与 Plugins 之间），不读取其它任何东西。它的注入面通过保留的 `hooks` 隔间发布控制器快照（绑定为 `useLearn`），外加一个 `load` 回调；组件只渲染这些属性。它随自己的 fiber 一起卸载，因此插件重载会移除标签页及其字典。

读取在标签页首次渲染时开始，而不是插件加载时：从不打开「了解更多」的人不会产生任何请求。

## Model Experience

无；这是一个渲染服务器所提供说明的设置页面，不注册模型上下文，也不写入会话事件。

#### KV Cache effect

无；这个浏览器插件既不组装提供方请求，也不写入会话事件。

## 已知限制与待办

- 需要家庭 e-server 源提供 `GET /v1/browser/learn`。没有该路由的部署会显示一个点明 404 的失败，而不是空白标签页。
- 说明每次页面加载只读取一次。服务器上的说明修改在刷新后（或从失败状态重试后）生效；没有轮询，也没有实时刷新。
- 出现哪些助手完全由服务器的「名单 ∩ 已组合预设」规则决定；插件无法用来说明服务器未包含的助手。
- 组合后的浏览器界面由协调者在合并后对真实源进行验证；本包的测试证明的是接口解析、控制器状态与真实响应体下的渲染，而不是部署后的页面。
